Optimization Model

1. Decision Variables

\[x_i = \text{Number of items handled from category }i \text{ in 3 months}\]

2. Objective Function

Maximize the total revenue: \[\text{Maximize } Z = \sum_{i=1} r_i\cdot x_i\]

where \(r_i\) is the revenue per item from category \(i\).

3. Constraints

  1. Capacity Constraint: The total number of items handled should not exceed the maximum capacity \(C\). \[\sum_{i=1} x_i \leq C\]

  2. Demand Constraint: The number of items handled from each category should not exceed the demand \(D_i\) for that category. \[x_i \leq D_i \;,\quad \forall i\]

  3. Non-negativity Constraint: The number of items handled from each category should be non-negative. \[x_i \geq 0 \;,\quad \forall i\]

Role of Data in the LP model

Model Component Data Required
Objective coefficients \(r_i\) Average revenue per item
Demand limits \(D_i\) Historical category sales
Capacity \(C\) Historical throughput

Demand Estimates \(D_i\) (Next 3 Months)

\[D_i = \text{Average Monthly Sales}_i \times 3\]

\(\text{Average Monthly Sales}_i = \dfrac{\text{Total hostorical Sales}_i}{\text{Total months}_i}\)

Linear Programming Model Setup

categories = category_stats['product_category_name'].tolist()
n = len(categories)
r_i = category_stats['avg_revenue_per_item'].values

c = -r_i

Capacity Constraint: \(\sum x_i \leq C\)

A_ub = np.ones((1, n))
b_ub = [capacity_3_months]

Demand Constraint: \(x_i \leq D_i\)

A_demand = np.eye(n)
b_demand = category_stats['demand_3_months'].values

A_ub = np.vstack([A_ub, A_demand])
b_ub = np.concatenate([b_ub, b_demand])

Non-negativity Constraint: \(x_i \geq 0\)

bounds = [(0, None) for _ in range(n)]

Solving the LP Model

result = linprog(
    c=c,
    A_ub=A_ub,
    b_ub=b_ub,
    bounds=bounds,
    method='highs'
)
category_stats['optimal_quantity'] = result.x
category_stats['optimal_revenue'] = (
    category_stats['optimal_quantity'] *
    category_stats['avg_revenue_per_item']
)
